# Frases para aprobar

Textos que hoy ven las personas que usan Careonys y que tienen una redacción dudosa o hablan de «invitación». Cada ficha muestra el texto actual, una propuesta y dónde aparece, para decidir uno por uno.

Cada propuesta sigue las pautas de Microsoft y de Google para mensajes: oraciones completas, en voz activa; primero qué pasó y después qué hacer; sin culpar a quien lee y sin palabras internas del sistema. **¿Aparece hoy?** dice si la frase puede salir en pantalla tal como está el código; las que no, se proponen para sacar.

**Total: 3 fichas.** Panel 3.

## Panel (3)

### 43. Falta cómo recibe el trabajo

| | |
|---|---|
| **Texto actual** | Marque al menos una forma de recibir el trabajo. |
| **Propuesta** | «Marque al menos una modalidad: Prestación directa o Match.» |
| **¿Aparece hoy?** | sí |
| **Por qué** | «forma de recibir el trabajo» no dice de qué se trata. Las casillas son las modalidades, y así las llama el resto del Panel; nombrarlas dice exactamente qué marcar. |
| **Quién lo lee** | la administración de la Prestadora. El Asistente no lo ve. |
| **Dónde está** | Panel → Padrón de Asistentes, ventana «Nuevo Asistente»; Panel → Padrón de Asistentes → Legajo, solapa «Perfil». |
| **Qué estaba haciendo** | en el grupo «Cómo recibe el trabajo» desmarcó Prestación directa y Match, y guardó. |
| **Qué pasó** | no se guardó: un Asistente sin ninguna modalidad no puede recibir guardias. |
| **Qué puede hacer después** | marcar Prestación directa, Match o las dos, y guardar. |
| **Cómo se muestra** | franja. |
| **Decisión** | queda para después de la mudanza: se decide con el reclutamiento. |

### 47. Asistente no Activo para el certificado

| | |
|---|---|
| **Texto actual** | El Asistente no está Activo. Cambie su estado en la solapa Perfil para emitir el certificado. |
| **Propuesta** | «El Asistente no está Activo. Para emitir el certificado, cambie su estado a Activo en la solapa Perfil.» |
| **¿Aparece hoy?** | sí |
| **Por qué** | el texto actual ya dice qué pasó y qué hacer. La propuesta pone primero para qué y dice a qué estado cambiarlo. |
| **Quién lo lee** | la coordinación de la Prestadora. |
| **Dónde está** | Panel → Padrón de Asistentes → Legajo, solapa «Certificado de Aptitud». |
| **Qué estaba haciendo** | abrió la solapa para emitir el certificado. |
| **Qué pasó** | el Asistente está Inactivo o Cesado. El botón «Emitir Certificado» queda apagado. |
| **Qué puede hacer después** | ir a «Perfil», pasarlo a Activo y volver. |
| **Cómo se muestra** | franja. |
| **Decisión** | queda para después de la mudanza: se decide con el reclutamiento. |

### 49. Consentimiento firmado por otra persona

| | |
|---|---|
| **Texto actual** | El consentimiento guardado lo firmó una persona distinta del Pagador actual. Revise el consentimiento. |
| **Propuesta** | «El consentimiento guardado no lo firmó el Pagador actual. Arme un consentimiento nuevo para que lo firme.» |
| **¿Aparece hoy?** | sí |
| **Por qué** | «Revise» no dice qué hacer. «Arme» es el verbo del botón «Armar el consentimiento», y la salida habitual es un consentimiento nuevo firmado por quien paga hoy. |
| **Quién lo lee** | la coordinación de la Prestadora que puede editar los datos del Cliente. |
| **Dónde está** | Panel → Clientes → un Cliente → solapa «Contacto», recuadro «Quién paga». |
| **Qué estaba haciendo** | revisaba o cambiaba quién paga. |
| **Qué pasó** | se cambió el Pagador después de la firma, por ejemplo. El aviso no frena nada. |
| **Qué puede hacer después** | ver el documento firmado, armar un consentimiento nuevo o cambiar el Pagador. |
| **Cómo se muestra** | franja. |
| **Decisión** | se resuelve junto con el cambio, el desistimiento y la pluralidad del Pagador. |
