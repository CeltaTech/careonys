# Legislación — Suecia

Este documento cita las normas propias de Suecia que alcanzan a Careonys y dice para cada una en
qué estado está el sistema. Además de lo que está acá, a Suecia le alcanza todo lo de
`docs/legal/union_europea.md`. Los tres estados posibles («Cumple», «En obra», «No alcanza») y qué
significa cada uno están explicados en la introducción de `docs/CUMPLIMIENTO_NORMATIVO.md`.

## Acceso a los datos del paciente

- **Patientdatalagen 4 kap. 2 §** — el acceso exige relación de cuidado con el paciente. No alcanza
  con pertenecer a la organización. **En obra** — paso 121.
